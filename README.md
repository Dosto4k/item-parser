# Описание

Парсер информации о предметах из игры Escape From Tarkov

# Парсит следующую информацию о предметах:
- Какие предметы нужны для выполнения квестов
- Сколько определённых предметов нужно найти
- Сколько предметов нужно найти в рейде
- Сколько предметов можно не находить в рейде

# Запуск
- Для запуска необходимо установить [uv](https://docs.astral.sh/uv/)
- Клонируем репозиторий
- Переходим в корень проекта
- Выполняем `./main.py`
